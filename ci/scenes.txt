# The screens CI renders on the Duo simulator (ci/screenshots.sh), one a line:
#
#   name | tier | poses | variants | launch arguments | tap
#
#   tier      core: on every push that touches the app; full: with everything else, when
#             the design system or ci/ changes, or on a manual run
#   poses     closed (the outer display), open (the inner one)
#   variants  default; large (the accessibility-large text size); contrast (Increase Contrast)
#   launch arguments  `-scene <name>`: the app opens that scene (App/Sources/Scenes/Scene.swift,
#             debug builds in the simulator only), from the sample world, Breakwater
#             (SampleWorld), with the companion playing a script; `-fixture empty` for a world
#             with nothing in it, `-keyboard YES` for the keyboard up as well. A scene presents
#             its own sheet, alert or keyboard after launch, and makes Documents/scene-ready in
#             the app's container when its screen is final, which is when the shot is taken,
#             with Documents/scene-metrics.json beside it: the page's type, measured.
#   tap       a control's label to tap before the shot, for an open menu (optional)
